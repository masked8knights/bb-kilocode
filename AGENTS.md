# AGENTS.md

When adding a feature to this plugin, study how these already do it, then adapt.
Do not copy chrome this plugin left out.

- [Kilo Code docs](https://kilo.ai/docs) — the CLI this plugin drives: settings, models, session modes
- [Agent Client Protocol](https://agentclientprotocol.com) — the protocol the adapter proxies
- [BB provider plugin API](https://github.com/get-bb/bb) — registration, bridge, maintenance surfaces
- [Paseo](https://github.com/getpaseo/paseo) — multi-agent orchestration; several agents as providers
- [T3 Code](https://github.com/pingdotgg/t3code) — agent control surface; one of several providers
